## kaggle 

Get Kaggle API Credentials:

Log in to your Kaggle account.
Go to Account > API and click Create New API Token. This downloads a kaggle.json file.
Configure Kaggle CLI:

Place kaggle.json in your home directory under a folder named .kaggle (i.e. ~/.kaggle/kaggle.json).

chmod 600 ~/.kaggle/kaggle.json
